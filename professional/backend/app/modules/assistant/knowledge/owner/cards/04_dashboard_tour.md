Top menu: **Dashboard** and **Projects**. The top bar also has search, the notification bell, messages (chat icon), language and your avatar menu (Profile Settings, Dark Mode, Help & Feedback, Logout).

Dashboard sections:
- **Our Services**:
  - **Construction Project**: start a new project.
  - **Buy & Sell**: property.
  - **Book Technician**: plumber, electrician and more.
  - **Order Product**: materials. This needs a self-construction project.
- **Available Technicians**: Painter, Plumber, Electrician, Carpenter, each with **Book Now**.
- **Construction Materials** from suppliers.
- Totals: Total Projects, In Progress, Overall Progress, Pending Requests.
- **Recent Activity** (requests, with Accept / Reject), **Upcoming Deadlines**, **Project Status**, **Budget Across Projects**.

Inside a project (open it from Projects):
- **Hire Builder** projects have these tabs: Find Builders, Requests, Assign Builder, Site Activity, Live Camera, Overview, Project Analysis, Escrow, Payments.
- **Self Construction** projects have these tabs: Requests, Site Engineer, Suppliers, Site Activity, Live Camera, Overview, Project Analysis, Escrow, Payments.
