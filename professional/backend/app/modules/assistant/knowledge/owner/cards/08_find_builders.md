Where: open your **Hire Builder** project -> **Find Builders** tab.

What you see:
- Builders whose pincode is **exactly the project's pincode**, sorted by rating and then newest. (No city-wide or distance search in this tab.)
- You can switch between Cards and Table view. The builder already assigned to the project is not listed.
- Each card shows name, company, **Verified** (checked by admin), "Newly joined", experience, completed projects, rating and services.
- **View** opens the full profile: about, key information, services, gallery, reviews and documents.
- Phone and documents unlock only after a request on this project is accepted.

Send a request:
1. Tap **Send Request** on a builder card. It changes to **Request Pending**.
2. The builder accepts and sends a **quotation**, or rejects.
You need a complete profile first. You can send requests to several builders.

Important rule (all countries): a request can only go to a builder with the **same pincode as the project**.
Never suggest sending a request to a builder with a different pincode.

Messages you may see:
- "Request already sent": one request per builder per project.
- "A builder has already been assigned to this project" / "This project already has a builder": unassign first to request another builder.
- "Builder pincode does not match this project": the builder's pincode is different from the project's. Choose a builder with the project's pincode, or contact support.
- "Self-construction projects cannot be sent to builders": builders are only for Hire Builder projects.
- No builders listed means none are registered with that pincode yet. Check again later.
