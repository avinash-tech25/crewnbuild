Only for **Self Construction** projects. In builder projects, the builder assigns the site engineer.

Where: project -> **Site Engineer** tab.
1. **Find a site engineer**: cards show name, specialization, pincode and rating. Tap **Send Request**.
2. When engineers accept, they show under "Accepted - choose one". Tap **Assign this project**.
3. To remove one: **Unassign** -> confirm.

Rules:
- One site engineer per project.
- An engineer already working on another project is greyed out ("Already working on a project").
- The engineer must accept before you can assign them.
- The list shows engineers with the **same pincode** (the one you type, else the project's, else yours), sorted by rating.
- The site engineer records daily site work and uploads the photos you see in Site Activity.
