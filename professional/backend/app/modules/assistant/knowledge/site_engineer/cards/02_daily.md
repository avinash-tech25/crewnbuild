- Record each working day of an assigned project in the **Calendar**: work done, labour, material usage,
  expenses, photos and videos.
- **Daily Logs** lists the records you have written. A day's record can be edited while that day is open.
- Material used in a daily record lowers the project's store stock, the same stock as **Store**.
